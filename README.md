# CRT-Custom-Buttons
Map CRT buttons to Chines universal board

Some deatils about it can be found here: https://github.com/misterblack1/yichuang_crt_board/tree/main

I both the board on Alliexpress to fix my old CRT from 1982.

Chalange was to reuse exiting buttons on it.

Here is a simple arduino code which emulates IR remote and have exisitng CRT buttons connected to it.
